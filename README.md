# 🥊 BOXTIMER PRO — Timer de Boxe (PWA)

Timer de Boxe profissional de alta visibilidade, otimizado para smartphones (iPhone/Safari e Android), com campainha/gongo sintetizados via **Web Audio API** e suporte **100% offline**.

## ✨ Recursos
- **Configurações Ajustáveis**: Tempo de Round, Tempo de Descanso, Número de Rounds, Tempo de Preparação e Aviso de 10s finais.
- **Alto Contraste Dinâmico**:
  - 🟢 **Verde**: Round ativo
  - 🟡 **Amarelo Pulsante**: Últimos 10 segundos do round
  - 🔴 **Vermelho/Laranja**: Intervalo de descanso
- **Web Audio API (Zero arquivos externos)**: Gongo metálico realista, *clapper* tradicional de 10 segundos e bips nos 3 segundos finais.
- **PWA Completo**: Instalável na Tela de Início do iOS e Android em modo tela cheia (`standalone`), com `Service Worker` offline e `Screen Wake Lock API` para manter a tela acesa durante o treino.
